# 示例

两个真实形状的例子，来自 `D:\spaceEXP\superINR` 的实验记录，只做示范，不含完整数据。

| 文件 | 展示什么 |
|---|---|
| `C001-depth-full.md` | 一条**已结算**的断言：判据、证据、结论、威胁都在 |
| `C002-多尺度.md` | 一条**未执行**的断言：判据在跑之前就写死了 |

对比两者能看出 labkit 想固定下来的东西：**判据的写作时间**。

C001 的判据在跑 384 组之前就定了（全部像素监督、配对差、≥1.5 dB）；
C002 的判据现在就写，而实验还没开始。如果反过来——先跑完再回头写"我认为应该 ≥0.3 dB"——
那么判据只是对结果的描述，不具备否证能力。

## 关于证据链接

示例里的 `out=` 指向的是真实的产物目录。注意它们**只被引用，没有被复制**——
数字留在 `results.csv` 里，claim 文件只负责说"看哪一份、按什么条件筛"。
