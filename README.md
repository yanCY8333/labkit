# labkit

提升 AI agent 编码时代人机协作效率的模板项目。

结构在 `seed/` 里：

```text
AIWORK/      AI 的工作区，随便写
  Prototype/   baseline 原始仓库，拷进来就不动
  Experiment/  一个实验一个目录，README 给人类看
    data/      高度复用的数据池，按类型细分，引用不拷贝
    environ/   复现基底：环境记录、冻结协议、共享默认配置
  Status/      交接窗口 + 全局节点 + inter 总览页 + 归档
REVIEW/      人类确认节点后 AI 放入的代码与结果快照，人类在此审核
HUMAN/       审核后晋升的最高净值内容，只能由人类最终确认进入
```

语言分工：AI 读的（`AGENTS.md` 和所有 `agent_` 前缀文件）是英文——LLM 的母语是英语；人类读的说明书双语。

命名约定：区全大写，区内层首字母大写，再往下一律小写。没有脚本：建实验、打快照、校验哈希、刷新 inter 全是 agent 照规则手工做的。

## 启动方法

​	直接在 agent 中对 AI 说，生成协议见本仓库 `AGENTS.md`。

## 设计要点

- 三区权限：AIWORK AI 可写（开新方向要人类点头）；REVIEW 只进快照、进后不改（sha256 清单作证）；HUMAN 是高净值区域，必须经由人类的审核确定。
- append-only：不做任何修改，只做增量记录。流水有六种动作（N 新建 / R 运行 / F 修正 / M 节点 / P 晋升 / X 失败），讨论和推理在 agent 内部，不作为事实进入工作区。
- 判据先于结果：不做总结性结论，只做实验数据汇总，结论由人类决定。
- 真实时间戳：机器时钟、含秒、带 UTC 偏移，实现完整证据链存在。
- inter.html：`AIWORK/Status/` 下的自包含总览页——方向/实验/结论/统计/逐 bench 表 + 人类的本机笔记；跑动实验由 watcher 刷 live 区，页面自动重载。
